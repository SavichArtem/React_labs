# Freelance Platform

## Использованная библиотека

**Bootstrap 5.3** - современный CSS-фреймворк для создания адаптивных веб-интерфейсов.

## Использованные компоненты Bootstrap

В проекте использованы следующие компоненты Bootstrap:

### `BootstrapButton`
Универсальная кнопка с вариантами стилей. Используется в Header, HeroSection, FeaturesSection, FreelancerCard, ContactSection, GettingStarted.

### `BootstrapModal`
Всплывающее модальное окно. Используется в Header для отображения информации о платформе.

### `BootstrapNavbar`
Навигационная панель. Используется как основной контейнер для навигации в Header.

### `BootstrapNav`
Контейнер для элементов навигации. Используется в компоненте Navigation для отображения пунктов меню.

### `BootstrapDropdown`
Выпадающее меню. Используется в Header для меню "Аккаунт".

### `BootstrapTooltip`
Всплывающие подсказки. Используется в Header для кнопки "Подробнее".

### `BootstrapCard`
Карточка для контента. Используется в FreelancerCard, FeaturesSection, GettingStarted.

### `BootstrapBadge`
Бейджи и метки. Используется в FreelancerCard для отображения рейтинга фрилансеров.

### `BootstrapAlert`
Оповещения и уведомления. Используется в ContactSection для информационных сообщений.

### `BootstrapProgress`
Индикатор прогресса. Используется в GettingStarted для визуализации шагов регистрации.

### `BootstrapSpinner`
Индикатор загрузки. Используется в FeaturesSection для визуального оформления.

### `BootstrapAccordion`
Аккордеон с раскрывающимися секциями. Используется в ContactSection для FAQ.

### `BootstrapCarousel`
Карусель изображений. Используется в HeroSection для демонстрации преимуществ платформы.

### `BootstrapOffcanvas`
Выдвижная панель. Используется в Header для мобильного меню.

### `BootstrapToast`
Всплывающие уведомления. Используется в HeroSection для отображения сообщений.
